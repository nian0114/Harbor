## 1. 背景与产品定位

用户需要一个 Termius 风格的现代化远程连接工作台：以 **Vault（凭据库）** 为中心管理主机、密钥、端口转发、代码片段，以 **多 Tab 终端 + SFTP + 图形远程桌面（VNC/RDP）** 为工作界面，并在此基础上强化三件 Termius 做得不够的事：

1. **云端账号联动**：一个账号登录多端，凭据端到端加密同步（macOS ↔ Android）。
2. **云端共享 Console**：一条 SSH 会话可选择性开启共享，多设备同时观看/操作同一个终端画面。
3. **会话完成监控**：长任务（尤其是 AI CLI，如 Claude Code / Codex / aider）结束时主动提醒用户"可以进行下一步了"。

差异化约束：**不使用 Electron / Web 壳**。核心协议与终端引擎用 **C** 实现为跨平台共享库，UI 用平台原生语言（macOS: Swift + AppKit/SwiftUI；Linux: C + GTK4/libadwaita；Android: Kotlin + Jetpack Compose），终端渲染走 GPU 原生管线。三端共用同一设计语言与图标系统（见 §6.1），桌面端（macOS/Linux）信息架构一致，移动端按 FR-17 重排。

## 2. 预期总目标（可度量）

| # | 目标 | 度量口径 |

## 3. 用户与核心场景

- **P1 运维/后端工程师**：管理几十台主机，跳板机 + 端口转发访问内网数据库；多端切换（工位 Mac、通勤 Android）。
- **P2 AI 辅助开发者**：在服务器上跑 AI CLI 长任务，切走干别的，任务完成时收到系统通知回来继续。
- **P3 家庭实验室/远程办公用户**：家里 Windows/桌面机只监听 127.0.0.1 的 RDP/VNC，借一台公网 SSH 主机穿透访问。
- **P4 结对/教学**：把当前 console 分享给自己的另一台设备或协作者实时观看/接管。

## 4. 范围

**In scope（V1.0）**：FR-01 ~ FR-13、FR-15、FR-16、FR-17（Android 交互规范）。
**P2 / V1.1**：FR-14 串口、Windows 桌面端（C core 已复用）、团队共享凭据库、会话录制回放、SFTP 断点续传增强。
**Out of scope**：Telnet、FTP（非 SFTP）、插件市场、Web 端。

## 5. 功能需求

> 每条需求包含：需求详情 / 预期目标 / 验收标准。验收标准均为可执行测试项，标注优先级 P0（MVP 必须）/ P1（V1.0 必须）/ P2（可延期）。

### FR-01 主机管理（Vault · Hosts）P0

**需求详情**
- 卡片/列表双视图展示主机：图标（按 OS 自动识别 Ubuntu/Debian/通用）、地址、协议与用户名（如 `ssh, nian`）、标签、分组。
- 顶部速连栏：输入 `user@hostname[:port]` 直接连接，支持模糊搜索主机名/标签/分组。
- New host 表单：别名、地址、端口、用户名、认证方式（密码/密钥/证书/agent）、跳板机（ProxyJump，可多级）、启动片段、保活间隔、颜色标签。
- 支持从 `~/.ssh/config` 导入；主机可拖拽入分组；右键：连接、SFTP、编辑、复制、删除。
- 单机双击即连；连接过程展示分阶段进度（解析 → TCP → 密钥交换 → 认证 → shell），失败给出人类可读原因与"编辑主机/重试"入口（对应截图 SFTP 连接日志页样式）。

**预期目标**：用户 10 秒内找到并连上任意已保存主机；新用户 1 分钟内完成首台主机配置并连通。

**验收标准**
1. 保存含跳板机（2 级）的主机后双击连接，`ssh -J` 等效链路建立成功，终端可交互。
2. 速连栏输入 `root@10.0.0.5:2222` 回车，使用正确端口发起连接。
3. 导入含 50 条目的 `~/.ssh/config`，主机数、Host 别名、IdentityFile、ProxyJump 映射全部正确。
4. 密码错误/主机不可达/指纹变更三类失败分别展示对应错误文案与操作按钮，不出现裸错误码。
5. 1000 台主机下列表滚动 ≥ 60fps，搜索响应 ≤ 100ms。

### FR-02 凭据库（Keychain）P0

**需求详情**
- 管理 SSH 私钥/公钥/证书/密码凭据；支持生成 Ed25519、ECDSA、RSA(≥3072)；导入 OpenSSH/PEM/PKCS#12，导出公钥。
- 私钥静态加密存储：macOS 存 Keychain/Secure Enclave 包装的数据保护密钥；Android 存 Keystore（StrongBox 优先）包装的 AES-256-GCM 密钥；应用内明文私钥仅存在于锁定内存页，用后清零。
- 生物识别解锁：macOS Touch ID（LAContext），Android BiometricPrompt；可配置"每次使用私钥签名需生物确认"。
- FIDO2/ECDSA-SK 密钥（`sk-ssh-ed25519`）：macOS 走 libfido2 + USB/NFC；Android 走 NFC/USB OTG。P1。
- SSH Agent 模式：可对接系统 `ssh-agent`；Harbor 自身也可作为 agent 供本机其它程序使用（macOS，P2）。

**预期目标**：私钥永不出设备明文边界（同步走 FR-11 E2EE）；签名操作可被生物识别门禁保护。

**验收标准**
1. 生成 Ed25519 密钥并用其登录 OpenSSH 9.x 服务器成功。
2. 开启"签名需 Touch ID/生物识别"后，每次连接均弹出系统生物弹窗；拒绝则连接中止且无明文残留。
3. 对应用沙箱/数据目录做静态取证：无法找到任何明文私钥或密码。
4. 导入带 passphrase 的 PEM key，首次使用询问 passphrase，可选择"记住（加密）"。
5. 删除凭据时级联提示引用它的主机数量，确认后主机认证方式回退为"未设置"。

### FR-03 SSH 终端与工作台 P0

**需求详情**
- 完整 VT 终端仿真（C 实现）：xterm-256color/truecolor、备用屏、鼠标上报、bracketed paste、OSC 8 超链接、OSC 52 剪贴板（可开关）、Unicode/emoji/CJK 宽字符、连字字体可选。
- 多 Tab；Tab 内可水平/垂直分屏成 **Workspace**（对应截图 12/13/14）；分屏支持 **Broadcast** 输入广播（带醒目边框标识）；Focus mode 单屏放大。
- 终端内查找（⌘F / 工具栏）、滚动回看（默认 10,000 行可配）、字体/字号/主题（内置暗色如截图、亮色、Solarized 等）、透明度。
- 命令自动补全（Beta，基于历史与远端 PATH 提示，默认关闭，对应截图 14 右侧栏）。
- 断线自动重连（指数退避），重连后提示会话已丢失/恢复（若远端在 tmux 内给出 attach 建议）。
- 快捷键体系与 Termius 对齐：⌘T 新 Tab、⌘K 清屏/搜索面板、⌘⇧M focus 等，可自定义。

**预期目标**：作为日常主力终端无功能短板；vim/htop/tmux 等全屏应用显示与交互正确。

**验收标准**
1. `vttest` 核心用例通过率 ≥ 95%；vim、htop、tmux、less 中文文件显示与按键行为与 iTerm2 一致。
2. 2 分屏 + Broadcast 开启时，输入 `uptime` 两屏同时执行；关闭后仅当前屏收到输入。
3. `cat` 100MB 文本：macOS 完成渲染 ≤ 2s 且 UI 不冻结；Android ≤ 8s。
4. 拔网线 30s 后恢复：客户端自动重连并给出明确状态条；期间输入有本地缓冲提示。
5. 终端内搜索关键字可高亮全部命中并上下跳转。

### FR-04 本地终端（Local）P0

**需求详情**
- macOS：内置 Local 终端，启动用户默认登录 shell（`$SHELL`，zsh/bash/fish），完整 PTY，继承用户环境变量；可与 SSH Tab 混排、分屏。
- Linux：与 macOS 同等能力的 Local 终端（GTK4 实现），默认登录 shell，支持 Wayland 下的剪贴板与 IME。
- Android：提供应用沙箱内的本地 shell（`/system/bin/sh` + 内置 toybox 工具集），可选安装轻量 busybox 扩展；明确 UI 标注"设备本地（沙箱）"，不承诺 root 能力；支持从这里 `ssh` 出去的等价体验（即本地 shell 中运行内置 ssh 客户端命令，P2）。
- Local 会话同样纳入 FR-13 完成监控。

**预期目标**：不连服务器时 Harbor 也是合格的本地终端；Android 上提供可用的应急本地 shell。

**验收标准**
1. macOS Local Tab 中 `echo $SHELL`、`ls`、管道、Ctrl-C/Ctrl-Z、窗口 resize（SIGWINCH）行为与系统 Terminal 一致。
2. Android Local 中 `ls /sdcard`（授权后）、`ping`、`top` 可用；杀进程重启后会话正确标记为已结束。
3. Local 与 SSH 分屏共存时 Broadcast 可同时向两者发送输入。

### FR-05 SFTP 文件管理 P1

**需求详情**
- 独立 SFTP Tab；左右双栏（远端 ↔ 远端/本地 Local，对应截图 9/10），"Select host"侧栏选择第二端。
- 文件列表：名称/修改时间/大小/类型，排序、过滤、隐藏文件开关、面包屑 + 前进后退。
- 操作：上传/下载（拖拽 + 队列 + 进度 + 并发数可配）、新建文件夹、重命名、删除（确认）、权限编辑（chmod 可视化 rwx 矩阵）、Open with（下载到临时目录后调系统应用，保存回传提示）。
- 连接阶段可视化日志（Authentication…/Starting SFTP session…，对应截图 7），失败可 Edit host / Start over。
- 传输失败重试、同名冲突策略（覆盖/跳过/重命名）。

**预期目标**：替代 scp/命令行完成日常文件运维；大文件传输稳定可视。

**验收标准**
1. 上传 1GB 文件进度条平滑、速率显示正确，完成后远端 `sha256sum` 与本地一致。
2. 双栏从主机 A 复制到主机 B（经本机中转）成功。
3. chmod 644 → 755 后远端 `stat` 验证生效；隐藏文件开关能显示/隐藏 `.ssh`。
4. 传输中拔掉网络：任务标记失败并可一键重试，不产生损坏的远端半文件残留（写临时名后 rename）。

### FR-06 端口转发（Port Forwarding）P1

**需求详情**
- 三种类型：Local（-L）、Remote（-R）、Dynamic SOCKS5（-D）；表单化配置：绑定地址/端口、目标地址/端口、承载 SSH 主机。
- 规则可保存、可开关、显示实时状态（监听中/断开/流量计数）；支持"随主机连接自动启动"。
- 与 FR-07 联动：创建 VNC/RDP 主机时可一键生成配套 Local 转发规则（目标指向远端 127.0.0.1）。
- 端口冲突检测与提示；Remote 转发失败（服务端 GatewayPorts 限制）给出解释。

**预期目标**：无需记 ssh 命令行参数即可管理隧道；为图形远程桌面提供一键穿透。

**验收标准**
1. 建 Local 规则 `127.0.0.1:13306 → db.internal:3306`（经跳板主机），本机 `mysql -h127.0.0.1 -P13306` 连通。
2. Dynamic SOCKS5 规则开启后，`curl --socks5 127.0.0.1:1080` 出口 IP 为 SSH 服务器 IP。
3. 规则开关切换 ≤ 1s 生效；宿主 SSH 断开时规则状态变为"断开"并自动随重连恢复。
4. 绑定已被占用端口时保存前即提示冲突。

### FR-07 VNC / RDP 图形远程桌面（含 SSH 穿透）P1

**需求详情**
- 新增主机类型 `vnc` / `rdp`；连接后在 Tab 内打开原生渲染的远程桌面视图（C 协议栈：libvncclient / FreeRDP，渲染桥接到 Metal / Android Surface）。
- **回环穿透模式（核心场景）**：目标服务只监听服务器自身 `127.0.0.1:5901/3389` 时，表单勾选"通过 SSH 隧道连接"，选择一台可达的 SSH 主机（可与桌面目标同一台，也可为跳板），Harbor 自动：
  1. 建立 SSH 连接并开 Local 转发 `127.0.0.1:<随机空闲端口> → 127.0.0.1:<vnc|rdp端口>`（目标视角的回环）；
  2. VNC/RDP 客户端连接本地映射端口；
  3. 会话结束自动拆除隧道；隧道生命周期与桌面 Tab 绑定，UI 显示"经由 <ssh主机> 隧道"。
- RDP：NLA/CredSSP、用户名密码/域、分辨率自适应、剪贴板双向、音频重定向（P2）；VNC：密码认证、Tight/ZRLE 编码、自适应画质。
- 输入：macOS 完整键鼠 + 快捷键透传开关；Android 触控映射（单指移动/点击、双指缩放、长按右键、虚拟 Ctrl/Alt/Win/Esc 键条）。
- 画质/带宽档位（流畅/均衡/高清）；只读观看模式。

**预期目标**：服务器桌面服务不暴露公网也能安全连接；穿透配置零命令行。

**验收标准**
1. 实验环境：VNC 服务仅监听 `127.0.0.1:5901`，从外网经 Harbor"SSH 隧道"模式连接成功并可操作桌面；服务器 `ss -tlnp` 确认 5901 未对外监听。
2. RDP 同理经隧道连通 Windows 目标（xrdp/Windows 均可），NLA 认证通过，剪贴板双向可用。
3. 关闭桌面 Tab 后 5s 内本地映射端口释放、SSH channel 关闭。
4. 1080p 桌面在 Wi-Fi 下操作延迟主观流畅（帧率 ≥ 24fps）；断网后自动重连隧道并恢复画面。
5. Android 触控可完成"打开开始菜单 → 输入文字 → 关闭窗口"全流程。

### FR-08 代码片段（Snippets）与 Shell History P1

**需求详情**
- Snippet：标题、正文（多行）、可选变量占位 `{{var}}`（发送前弹窗填值）、作用范围（全局/指定主机/分组）。
- 终端侧栏一键发送到当前会话（Broadcast 开启时发送到全部分屏，需二次确认）。
- Shell History：聚合各会话执行过的命令（仅记录用户输入行，基于 OSC 133 / 提示符启发式），可搜索、可一键转 Snippet；云端同步可选（默认关闭，隐私考虑）。

**预期目标**：高频命令一次保存多端复用；减少重复敲长命令。

**验收标准**
1. 含 `{{path}}` 的 snippet 发送时弹变量框，填入后终端收到替换完成的命令。
2. snippet 在 Mac 创建后 ≤ 5s 出现在 Android 同账号列表中（FR-11 通道）。
3. History 不采集密码输入行（检测到 `password:` 提示后的输入不入历史）。

### FR-09 Known Hosts 管理 P1

**需求详情**
- TOFU 首连指纹确认弹窗（SHA256 指纹 + 随机艺术图可选），支持写入/读取 `~/.ssh/known_hosts`（macOS 导入，对应截图 5 Import）。
- 指纹变更时强警告（红色、说明中间人风险），需显式确认才更新；列表可查看/删除条目。

**预期目标**：杜绝静默接受主机密钥；MITM 风险显式暴露。

**验收标准**
1. 首连未记录主机必弹指纹确认；拒绝则连接终止。
2. 服务器重装（host key 变化）后连接出现红色警告，默认按钮为"取消"。
3. 导入 known_hosts 500 条无重复、hashed 条目（`|1|...`）正确匹配。

### FR-10 连接日志（Logs）P1

**需求详情**
- 记录连接级审计：时间、用户、主机、协议、结果、时长（对应截图 6 表格：Date/User/Host/Saved）；可收藏（Saved）、筛选、导出 JSON/CSV。
- 不记录终端内容与会话数据（除非用户显式开启会话录制，P2）；日志可本地保留期配置（默认 90 天），可选同步。

**预期目标**：可回溯"何时连过哪台、成败如何"，且不泄漏敏感内容。

**验收标准**
1. 成功/失败连接均产生一条日志，字段完整；失败含原因分类。
2. 导出 CSV 可被 Excel 正确打开（UTF-8 BOM）。
3. 抓包与本地库检查：日志中不含密码、私钥、终端输出。

### FR-11 云端账号与凭据同步（额外需求 #1）P0

**需求详情**
- 账号体系：邮箱 + 密码注册/登录（Argon2id 派生），可选 TOTP 两步验证；设备列表管理（名称、平台、最后在线时间、远程吊销）。
- **端到端加密（E2EE）**：
  - 主密钥 MK 由用户密码 + 随机盐经 Argon2id 派生，另生成随机数据密钥 DEK；MK 包装 DEK；所有 Vault 对象（主机、密钥、密码、snippet、转发规则、设置）在设备端用 DEK 以 XChaCha20-Poly1305 加密后才上传。
  - 服务端仅存密文 + 元数据（对象 id、版本、时间戳、类型），**零知识**：服务端无法解密任何凭据。
  - 恢复码：注册时生成 24 词恢复码离线保存，用于忘记密码时恢复 DEK（恢复码包装 DEK 的另一份副本）。
- 同步引擎：对象级版本向量 + 最后写入胜出（LWW）合并，冲突对象保留双版本供用户选择；增量推拉（WebSocket 通知 + 批量拉取），离线队列，恢复网络后 ≤ 5s 完成合并。
- 同步范围可选：主机/密钥/snippets/转发规则/known hosts/设置/历史（默认关）。
- 新设备登录流程：登录 → 拉取密文 → 本地解密 → 生物识别绑定本机 → 完成；全程服务端不见明文。
- 退出登录可选"保留本地副本"或"擦除本地 Vault"。

**预期目标**：换设备零手工迁移；服务端被拖库也不泄漏任何凭据。

**验收标准**
1. Mac 上新建主机 + 导入私钥 + 新建 snippet，Android 登录同账号后 10s 内三者全部可见且可直接连接成功。
2. 双端离线各改同一主机不同字段 → 恢复网络后自动合并不丢字段；改同一字段 → 出现冲突解决 UI，两个版本均可见。
3. 服务端数据库导出审计：所有敏感字段为密文；用服务端全部数据 + 源码无法还原私钥（需用户密码/恢复码）。
4. 错误密码登录不产生任何 Vault 数据下发；连续 5 次失败触发限流。
5. 在设备管理页吊销 Android 设备后，该设备 60s 内被登出且停止同步；已同步到该设备的数据可被远程标记擦除（下次联网时执行）。
6. 忘记密码走恢复码流程可完整恢复 Vault；无恢复码且无已登录设备时明确告知数据不可恢复（零知识代价，注册时已提示）。

### FR-12 云端共享 Console（额外需求 #2）P0

**需求详情**
- 会话所有者在已连接的 SSH/Local Tab 上点击"共享"开关，选择模式：**仅观看** / **可协作输入**；生成共享链接 + 6 位配对码（有效期可配，默认 30 分钟）。
- 同账号其它设备在"共享会话"入口直接看到进行中的共享；跨账号通过链接 + 配对码加入（V1.0 限同账号 + 链接匿名只读，协作输入仅限已登录用户）。
- 架构：所有者客户端将终端输出流（增量帧 + 定期全量快照）经 E2EE 加密后推送至 **Relay 服务**（WebSocket），观看端订阅同一会话频道；输入事件反向回传所有者客户端注入 PTY。**Relay 只转发密文，不解密**（会话密钥由所有者生成，经账号 E2EE 通道/配对码 PAKE 分发）。
- 多端同屏：新加入者先收全量快照（含 scrollback 尾部 N 行）再接增量，画面 ≤ 2s 内追平；resize 以所有者窗口为准，观看端 letterbox 适配。
- 所有者随时可见参与者列表（设备名/权限），可踢人、可一键停止共享；所有者断线共享自动结束并通知参与者。
- 共享状态在 Tab 上有醒目常亮标识（防止忘记在共享）。

**预期目标**：手机上无缝接管 Mac 上正在跑的会话；结对场景多人实时同屏。

**验收标准**
1. Mac 开启共享后，Android 同账号列表 5s 内出现该会话；加入后 2s 内画面追平，运行 `top` 画面持续同步刷新。
2. 协作模式下 Android 输入 `echo hi`，Mac 与所有观看端同步回显；只读模式下输入被拒绝且有提示。
3. 抓包 Relay 流量：无法还原终端明文内容。
4. 同城网络按键 → 对端回显 P95 ≤ 150ms；1% 丢包模拟下不花屏（快照修复）。
5. 所有者点"停止共享"后所有观看端 3s 内断开并提示；所有者直接关 App，观看端 10s 内收到结束通知。
6. 5 个观看端同时在线，所有者端 CPU 增幅 ≤ 15%。

### FR-13 会话监控与完成提醒（额外需求 #6）P0

**需求详情**
- 对每个 Tab/分屏会话提供"监控"开关（默认对 SSH 会话开启），检测以下**完成信号**，任一命中即触发提醒：
  1. **进程/会话结束**：SSH channel EOF / 本地 shell 退出（最强信号）。
  2. **OSC 133 语义提示符**：shell 集成标记命令结束（含退出码），可区分成功/失败；提供一键安装 shell 集成脚本（zsh/bash/fish）。
  3. **输出模式规则**：用户可配置正则/关键字规则（全局 + 按主机），内置 AI CLI 预设：Claude Code 完成提示、Codex、aider、`npm build` 完成、`pytest` 结果行等；命中后进入"等待输入"判定。
  4. **空闲启发式**：持续输出 ≥ N 秒后静默 ≥ M 秒且光标停在输入态（默认 N=10, M=5，可配），作为兜底信号，置信度较低。
  5. **BEL / OSC 9 / OSC 777** 终端通知转系统通知。
- 提醒通道：应用内通知中心（铃铛，含未读角标）、Tab 角标（绿√成功 / 红×失败 / ●待查看）、macOS 系统通知（UNUserNotificationCenter，点击直达该 Tab）、Android 通知（前台服务 + 通知渠道分级，点击直达）；可选声音。
- 免打扰：当前正聚焦该 Tab 时不弹系统通知只更新角标；全局勿扰时段。
- 提醒内容含：主机名、触发的命令（若 OSC 133 可得）、退出码/命中规则、耗时；敏感输出不外显（通知正文可配"仅主机名"）。
- 规则测试器：粘贴一段样例输出即时验证规则是否命中（防误报）。

**预期目标**：AI CLI 长任务跑完，用户无论在哪个 App 都能被准确叫回来；误报少到用户敢常开。

**验收标准**
1. 20 场景标准集（含 Claude Code/aider 完成、编译成败、下载完成、vim 打开中、top 运行中、纯 idle shell）：真完成召回 ≥ 95%，vim/top/idle 三类负样本误报 ≤ 5%。
2. SSH 会话远端 `exit`：≤ 2s 内 Tab 标记结束 + 系统通知；点击通知精确切到该 Tab。
3. OSC 133 集成下，命令失败（非零退出码）通知为红色样式并含退出码。
4. 用户正聚焦该 Tab 时命令完成：无系统通知弹出，仅角标变化。
5. Android App 退后台/锁屏 10 分钟后任务完成：系统通知仍送达（前台服务保活路径），点击直达会话。
6. 规则测试器对内置 AI 预设样例全部命中；对样例中间过程输出（如流式 token 行）不命中。

## 6. 非功能需求（NFR）

| 类别 | 要求 |
|---|---|
| 技术栈 | **禁止 Electron/WebView 壳做主 UI**。共享核心 C11：libssh2（+libcrypto）、自研/libvterm VT 解析、FreeRDP、libvncclient、libsodium、SQLite。macOS：Swift + AppKit（终端视图 Metal + CoreText 渲染）。Linux：C + GTK4/libadwaita（终端视图 GTK GL Area + Cairo/Pango 渲染，Wayland 优先）。Android：Kotlin + Jetpack Compose（终端视图 Surface + Canvas/GLES 渲染），C core 经 JNI 桥接。 |
| 服务端 | 同步 API + Relay：语言建议 Rust 或 Go（服务端不受"客户端 C/原生"约束；若坚持 C 可用 libwebsockets + SQLite/Postgres）。零知识存储；Relay 无状态可横扩。 |
| 安全 | TLS 1.3 + 证书锁定；E2EE 见 FR-11/12；私钥内存 mlock + 用后清零；防截屏可选（Android FLAG_SECURE 用于凭据页）；依赖 CVE 月度扫描。 |
| 性能 | 见 G1/G2/G4；终端输入延迟（本机回环）≤ 8ms。 |
| 可靠性 | 崩溃率 < 0.1% 会话；所有网络操作有超时与取消；本地 DB WAL + 原子迁移。 |
| 兼容性 | macOS 13+；Linux：Ubuntu 22.04+/Fedora 38+/Arch（GTK 4.10+，X11 与 Wayland），deb/rpm/AppImage/Flatpak 分发；Android 10+，适配平板/折叠屏分栏；SSH 服务端兼容 OpenSSH 7.4+ / Dropbear。 |
| 无障碍/国际化 | VoiceOver/TalkBack 覆盖主流程；中英双语；CJK 宽字符渲染正确。 |
| 隐私 | 默认不采集使用遥测；崩溃上报需 opt-in 且脱敏。 |

## 7. 系统架构（概要）

```
┌─────────────────────────── 客户端 ───────────────────────────┐
│  macOS UI (Swift/AppKit, Metal 终端渲染)                      │
│  Linux UI (C/GTK4+libadwaita, GL 终端渲染)                    │
│  Android UI (Kotlin/Compose, Surface 终端渲染)                │
│            │  C ABI / JNI（统一接口层 harbor_core.h）          │
│  ┌─────────▼───────────────── C Core ─────────────────────┐  │
│  │ ssh(libssh2) │ vt(终端状态机) │ sftp │ pf(转发)          │  │
│  │ vnc(libvncclient) │ rdp(FreeRDP) │ serial               │  │
│  │ vault(SQLite+libsodium E2EE) │ sync(增量/冲突合并)       │  │
│  │ share(帧编码+加密+WS) │ watch(完成信号引擎: EOF/133/规则) │  │
│  └────────────────────────────────────────────────────────┘  │
└───────────────┬──────────────────────────┬───────────────────┘
                │ TLS1.3                   │ WSS（仅密文帧）
        ┌───────▼────────┐         ┌───────▼────────┐
        │ Sync API       │         │ Relay 集群      │
        │ 账号/设备/密文  │         │ 会话频道 PubSub │
        │ 零知识存储      │         │ 无状态、不落盘  │
        └────────────────┘         └────────────────┘
```

关键设计点：
- **C core 单写者事件循环**（每会话一个 loop，epoll/kqueue），UI 只消费快照与事件流，保证线程安全与低延迟。
- **同步对象模型**：`{id, type, version_vector, encrypted_blob, updated_at, tombstone}`；LWW + 冲突副本。
- **共享帧协议**：`SNAPSHOT`（VT 状态序列化）+ `DELTA`（输出字节段）+ `INPUT` + `PRESENCE`；密钥经账号 E2EE 通道分发，Relay 零知识。
- **完成信号引擎**：VT 解析器旁路输出 tap → 规则匹配（RE2 风格 C 实现）+ OSC 133 状态机 + 空闲计时器 → 置信度融合 → 通知去抖（同会话 30s 内合并）。

## 9. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| FreeRDP/libvncclient 在 Android 的构建与裁剪体积 | 高 | M0 即做交叉编译 spike；RDP 可先只支持核心 profile |
| VT 兼容性长尾（自研解析器） | 高 | 基于 libvterm 起步 + vttest 回归集 |
| Android 后台保活厂商差异（HyperOS/EMUI 杀后台） | 高 | 前台服务 + 白名单引导 + 断线推送兜底（服务端探测会话结束发 FCM，P2） |
| 零知识忘记密码 = 数据丢失投诉 | 中 | 恢复码强引导 + 注册时明确告知 + 已登录设备互相授权恢复（P2） |
| 共享 Relay 带宽成本 | 中 | 增量帧 + 压缩 + 空闲降频；观看端数量上限（默认 5） |
| AI CLI 输出格式变化导致规则失效 | 中 | 规则云端可热更新（签名下发）+ OSC 133 优先 + 空闲兜底 |

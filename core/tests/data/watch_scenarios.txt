# Harbor watch engine — FR-13 acceptance-1 standard scenario set (20 scenarios).

# Format (one directive per line; '#' comments, blank lines ignored):
#   scenario <name> <expect> [<signal>] [neg:<class>]
#       expect  ok | err | none      (first hit's ok flag, or no hit at all)
#       signal  expected hit signal  (eof|osc133|rule|idle|bell|osc9|osc777); optional
#       neg:<class>  marks an acceptance negative class (vim|top|idle) for FP rate
#   @<ms> out <str>             feed output bytes
#   @<a>-<b>/<step> out <str>   feed <str> every <step> ms from a to b inclusive
#   @<ms> in                    user input (keystroke)
#   @<ms> 133 <mark> [<code>]   OSC 133 event (A|B|C|D; D carries exit code)
#   @<ms> bell                  BEL
#   @<ms> osc9 <body>           OSC 9 notification
#   @<ms> osc777 <title>|<body> OSC 777 notify
#   @<ms> eof <code>            session ended
#   @<ms> end                   stop; poll the engine at every ms step up to here
# <str> uses C escapes: \e \a \r \n \t \\ \xHH. Everything after the keyword's
# single separating space is the string (leading spaces are preserved).
# All scenarios run with hb_watch_cfg_defaults() (idle heuristic OFF).
